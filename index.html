How to use a CSSBuy spreadsheet

Save one row for each exact size and color you are considering. Keep the source link, measurements and estimated total together so you can compare options before ordering.

  1. 1. Confirm the listingOpen the CAFANS product page and check its agent options. If you plan to order through CSSBuy, confirm that it accepts the seller link and that your selected variant is available.
  2. 2. Check size and warehouse photosCompare the seller’s measurements with a similar item you own. If warehouse quality-control photos are available, check the variant, labels, stitching and visible defects before you authorize shipping.
  3. 3. Compare the full costUse the same currency and destination for each quote. Confirm whether the carrier uses actual or volumetric weight and whether packaging changes the price.

Common questions

Can I use these CAFANS listings with CSSBuy?

Check the agent choices on each product page. If you have the original seller URL, confirm that CSSBuy can process it and that the exact size and color are available before paying.

What should I record for shoes and clothing?

For shoes, record the seller’s size system and any available insole measurements. For clothing, compare garment measurements such as chest width, shoulder width and length with something you already own.

What are QC photos?

QC photos show the item received at the agent’s warehouse when that service is available. Use them to compare the received item with the selected color and size, and ask about unclear details before shipping.
